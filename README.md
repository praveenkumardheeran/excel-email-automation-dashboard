# Excel Email Automation Dashboard

An Excel-based Email Automation Dashboard project built for practicing advanced Excel skills like XLOOKUP, Data Validation, dynamic email templates, and dashboard creation.

---

## 📌 Project Overview

This project simulates a real-world employee email management system using Microsoft Excel. It automatically fetches employee details and generates professional email templates using lookup functions and interactive Excel features.

The project is useful for:

* Excel practice
* Data Analyst portfolio
* MIS Executive preparation
* Office automation learning
* Dashboard design practice

---

## 📂 Sheets Included

### 1. Employee_Data

Contains employee information such as:

* Employee Name
* Email Address
* Salary
* Role/Designation

---

### 2. Email_Templates

Contains:

* Email Subject
* Professional Email Body Templates

Examples:

* Salary credited
* Meeting invitation
* Leave approval
* Promotion announcement
* Training reminder

---

### 3. Dashboard

Interactive dashboard where users can:

* Select employee names
* Auto-fetch employee email
* Select email subject from dropdown
* Generate email body automatically
